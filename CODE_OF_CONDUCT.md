# Code of conduct

Be kind, be patient, assume good intent. People here range from first-time contributors to seasoned developers, and everyone is welcome.

Not okay: harassment, insults, personal attacks, discriminatory jokes or language, publishing someone's private information, and anything else you would not accept in a professional setting.

This applies in issues, discussions, pull requests and anywhere else you represent the project.

If something happens, tell the maintainer privately through a [private report](https://github.com/SnlperStripes/claude-account-switcher/security/advisories/new) or use GitHub's **Report content**. Comments, commits or contributions that break these rules can be removed, and repeat offenders blocked.

Based on the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
